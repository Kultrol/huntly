# 🎯 Huntly

A simple **job-application tracker** to keep your hunt organized.

## Live site

[Open Huntly](https://huntly-site.onrender.com). Huntly is in active development, and many planned features are still to come.

If the site has been idle, allow **about a minute** after opening it for the free Render backend to wake up. The page may appear before features like sign-in are ready.

## Available now

- Login page for existing accounts
- Registration page for creating an account
- Dashboard with upcoming events and an overview of roles, companies, and contacts

## What's to come

- Email verification for new accounts
- Stronger password validation, including a special character requirement
- Dedicated pages for roles, companies, and contacts
- Forms for adding new roles, companies, and contacts
- A settings page

## What's here

- `frontend/` — React + TypeScript + Vite UI
- `backend/` — Python API (WIP)
